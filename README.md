# Roadster

Roadster takes a photo of a car and returns scenes of that same car doing two stunts from Tesla’s October 2026 Roadster demonstration: a mid-air kickflip, and a flyover of a row of parked cars, with cold-gas thrusters. The car stays recognizable. This is a generated scene, not a real capability, and Roadster is not affiliated with Tesla.
